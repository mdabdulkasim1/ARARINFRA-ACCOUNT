# Logo

Drop the Arar INFRA logo in this folder as **`logo.png`** (or `logo.svg` — then
change the two `<img src>` references in `public/index.html` to match).

It appears on the sign-in card and in the sidebar. Anything roughly square works;
a transparent background looks best against the navy sidebar. Around 512×512 is
plenty.

Until the file is there, the app falls back to the "Arar INFRA" wordmark in the
brand colours, so nothing looks broken.
